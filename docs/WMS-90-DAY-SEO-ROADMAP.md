# WMS TRANSPORT 90-Day Evidence-Based SEO Growth Roadmap

## Strategic Phasing Overview

This roadmap balances immediate technical security and E-E-A-T compliance with systematic organic visibility expansion based on verifiable operational capacity.

---

### Phase 1: Days 1–14 — Deploy-Safe Corrections, Technical Gating & Measurement Baseline
* **Objective:** Secure crawlability, eliminate doorway penalty risks, protect internal routes, and establish clean measurement.
* **Key Tasks:**
  1. **Audit & Gate Unverified Pages:** Gate 14 Thonburi districts with true HTTP 404 until real job evidence is collected. Ensure only Bang Khae, Pinklao, and Maha Chai are indexed.
  2. **Vehicle Height Fact-Check:** Purge all claims of total vehicle height $le 2.1$m and basement parking access. Request owner physical measurements.
  3. **External Link & Dashboard Protection:** Remove unauthorized footer link (`kimx-wed.vercel.app`); add `noindex, nofollow` to `/dashboard/seo-intelligence`.
  4. **Google Search Console & Sitemap:** Request 16-month GSC export via `docs/GSC-DATA-REQUEST.md`; verify `sitemap.xml` contains 100% 200 OK indexable URLs.
  5. **Schema & E-E-A-T Integrity:** Maintain single Organization/MovingCompany entity with stable `@id`, BreadcrumbList, and visible FAQ schemas.
* **Deliverables:** Clean build, verified sitemap, GSC request document, zero crawl errors.

---

### Phase 2: Days 15–45 — High-Opportunity Page Optimization & Verified Case Study Publishing
* **Objective:** Maximize CTR and rankings on core transactional pages and publish first-hand case studies from real WMS jobs.
* **Key Tasks:**
  1. **GSC Performance Review:** Analyze 90-day search queries; identify keywords ranking positions 4–20 and optimize title/H1 alignment.
  2. **Publish 2–3 New Case Studies:**
     - Interview driver/team for recent completed moves (e.g. Samut Sakhon factory move, Bangkok-Phuket trip).
     - Format as verified `PortfolioCase` records with anonymized photos.
  3. **Evidence-Backed Unlock of Nong Khaem & Phasi Charoen:**
     - Collect 1 verified job record + original photo + genuine review for Nong Khaem and Phasi Charoen.
     - Move status from `draft_evidence_required` to `published` with proof scores $ge 80$.
  4. **Commercial Conversion Optimization:** Enhance CTA button tracking (LINE click, Phone click, Quote request) in Google Analytics 4.
* **Deliverables:** 2 un-gated district pages, 2 new portfolio case studies, GSC CTR improvements.

---

### Phase 3: Days 46–90 — Selective Provincial & Route Expansion
* **Objective:** Expand into verified high-demand transport corridors and provincial hubs.
* **Key Tasks:**
  1. **Recurring Corridor Expansion:**
     - Validate real repeat routes (e.g., Bangkok $leftrightarrow$ Chiang Mai, Bangkok $leftrightarrow$ Chonburi / EEC).
     - Create dedicated `/route/[from]/[to]` pages only for verified corridors with genuine distance, toll, and transit duration data.
  2. **Northern Thonburi Core Cluster Expansion:**
     - Once Bang Phlat / Bangkok Noi evidence is collected, publish corresponding district pages.
  3. **Customer Question Knowledge Expansion:**
     - Publish 2 high-intent guides addressing real customer inquiries (e.g., "วิธีขนย้ายตู้เย็นสองประตูอย่างปลอดภัย", "ขั้นตอนส่งมอเตอร์ไซค์ไปเกาะสมุย/ภูเก็ต").
  4. **Quarterly Technical & E-E-A-T Audit:**
     - Run full automated test suite and live crawler to verify zero broken links, zero duplicate titles, and complete schema compliance.
* **Deliverables:** 2 new verified route corridors, 2 published guides, quarterly SEO progress review.
